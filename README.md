🚀 科学计算与数学建模：深度学习与医药诊断综合实战
本仓库收录了《科学计算与数学建模》课程的 6 项核心实验。项目跨度从基础的统计学习回归分析到复杂的深度神经网络应用，最终落地于医疗影像识别与自然语言处理（NLP）的综合系统开发。

📂 实验内容深度解析
实验一：气象大数据预测 —— 线性回归建模 PM2.5
•	解决的问题：利用城市监测站过去 9 小时的 18 项气象指标（如 PM10、O₃、SO₂、风速等），精准预测第 10 小时的 PM2.5 浓度，辅助环境治理决策。
•	方法与模型：
o	模型：多元线性回归 (Multiple Linear Regression)。
o	核心算法：手动实现 Adagrad 优化算法，通过累积梯度平方和实现自适应学习率调整。
o	预处理：处理降雨量 "NR" 异常值，进行特征缩放（Scaling）以加速模型收敛。
•	实验结果：模型能够捕捉气象因素间的线性关联。实验证明，加入正则化项能有效抑制气象突变引起的预测震荡。
实验二：社会经济画像 —— 基于概率生成模型的二分类
•	解决的问题：基于美国人口普查数据（年龄、教育程度、婚姻状况、工时等），预测个人年收入是否超过 50k 美元。
•	方法与模型：
o	模型：概率生成模型 (Probabilistic Generative Model)。
o	算法逻辑：假设特征符合多维高斯分布，计算各类别的均值 $\mu$ 和共用协方差矩阵 $\Sigma$，利用贝叶斯定理推导后验概率。
•	实验结果：生成式模型在特征独立性较强时表现稳健。通过可视化发现，受教育程度和职业类型是区分高低收入的关键特征。
实验三：算法博弈 —— Logistic 回归与模型正则化
•	解决的问题：在相同的收入预测任务下，对比判别式模型（Logistic 回归）与生成式模型的性能差异。
•	方法与模型：
o	模型：Logistic Regression。
o	优化策略：
	L2 正则化：在损失函数中引入权重惩罚项，防止参数过拟合。
	早停法 (Early Stopping)：监控验证集 Loss，在模型开始产生泛化误差前自动中断训练。
•	实验结果：Logistic 回归的准确率优于生成式模型。通过 t-SNE 降维 可视化发现，判别模型能更好地刻画非线性边界。
实验四：连接主义基础 —— 深度神经网络 (DNN) 实践
•	解决的问题：探索神经网络深度与宽度对非线性空间映射能力的影响。
•	方法与模型：
o	模型：多层感知机 (MLP)。
o	方法：使用 Keras 搭建 Sequential 模型，对比 SGD、Adam、RMSprop 等不同优化器的收敛曲线。引入 Dropout 层进行神经元随机失活。
•	实验结果：深度增加能提升表达能力，但必须配合 Dropout 和合理的激活函数（如 ReLU）才能解决梯度消失和过拟合问题。
实验五：机器视觉 —— 卷积神经网络 (CNN) 与特征可视化
•	解决的问题：解决传统全连接网络处理图像时参数量巨大且丢失空间信息的问题。
•	方法与模型：
o	模型：CNN (Convolutional Neural Networks)。
o	架构：Conv2D（提取局部特征）+ MaxPooling（下采样/平移不变性）+ Flatten + Dense。
o	可视化方法：提取卷积层的 Filter 权重 和 Feature Map，直观观察机器如何从像素点提取边缘、纹理和几何轮廓。
•	实验结果：CNN 在图像分类任务上表现出压倒性优势，其提取的特征具有极强的层级性。
实验六：综合实战 —— 医药诊断评估系统
•	解决的问题：构建一个面向医疗场景的智能化分析系统，包含影像自动诊断与患者评价分析。
•	方法与模型：
1.	肺炎影像识别：针对医学 X 光片，采用 自编码器 (Autoencoder) 进行降噪预处理，再利用 CNN 进行病灶识别分类。
2.	药品评价情感分析：针对患者评论，使用 Embedding 层进行词向量化，通过 LSTM (长短期记忆网络) 提取文本的时序语义，实现积极、中性、消极的情感三分类。
•	实验结果：
o	影像识别模块通过 Autoencoder 过滤了拍摄噪点，准确率提升显著（最高达 81%）。
o	情感分析模块能准确捕捉评论中的转折语境（如“虽然...但是”），验证了序列模型在语义理解上的有效性。
